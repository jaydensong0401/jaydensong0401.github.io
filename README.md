## 구성

- 별도 빌드가 필요 없는 HTML·CSS·JavaScript 사이트입니다.
- GitHub Pages: `main` 브랜치의 `/ (root)`에서 게시합니다.
- `.nojekyll`을 사용합니다.
- 공통 스타일과 동작: `assets/site.css`, `assets/site.js`.
- 프로젝트별 페이지: 각 폴더의 `index.html`.
- 프로젝트의 실제 사용 로고·파비콘: `assets/brands/`.
- 순위나 확정 프로젝트 순서를 부여하지 않고 AX·AI / 서비스·운영 / 게임으로 구분합니다.
- 새 프로젝트는 폴더를 만들고 메인 페이지에 링크를 추가하면 됩니다.
- 문제·해결 설명과 면접 노트 원문은 `content/explanations/`에 프로젝트별 JSON으로 나눠 관리합니다.
- 수정 후 `python tools/render-explanations.py`로 사례 본문과 면접 노트를 함께 갱신합니다. 사용 방법은 `content/explanations/README.md`를 참고합니다.
- `/llm-wiki/`는 이전 주소입니다. 기존 링크를 위해 `/wiki-chatbot/`으로 자동 이동하는 페이지만 남겨 두었습니다.

## 공개 자료의 범위

공개용으로 정리한 소개 페이지와 가상 데이터 화면, 설명용 자료만 포함합니다.
운영 앱 소스 전체, 실제 메일·방문·정책 원장, DB, 계정과 인증 정보는 포함하지 않습니다.

- Mailwork 화면: 공개 샘플의 가상 데이터 데모 캡처.
- Wiki-ChatBot 화면: 사용자 요청에 따라 2026-10-21 촬영한 마스킹 전 실제 PC 원본 캡처 4장을 사용합니다. 기존 비식별 PNG 대신 JPG 원본을 표시하며, 새 촬영으로 표기하지 않습니다. 엑셀 청킹 설계와 내부 정책 추가 절차를 보강했습니다. 개편 기획: `wiki-chatbot/README.md`.
- 방문자 관리 화면: 원본 템플릿에 가상 데이터만 사용한 캡처.
- MJ Dashboard 화면: 공개 샘플의 가상 데이터 PC·모바일 캡처(2026-11-05, 뉴스·메일 포함 가상 예시).
- GLGYM 화면: 원본 UI 페이지·스타일을 별도 환경에서 실행한 가상 회원·수업 데이터 캡처. 실제 운영 DB·메일·푸시는 사용하지 않습니다.
- 게임 커버·콘셉트 이미지와 실제 플레이 화면은 각각 표시합니다. 게임 전체 기능을 개인 단독 기여로 소개하지 않습니다.
- 기존 증거 기록일과 이번 포트폴리오 갱신일은 구분합니다.
- 문서에 기재한 기능 확인과 실사용 성과 측정은 서로 다른 범위입니다.
- 7개 사례에 문제·원인·선택·대가·근거·다음 검증의 설명을 보강했습니다. 면접 노트의 답변은 준비용 초안이며 개인 담당·기간·실제 성과는 본인의 증빙으로 확정해 사용합니다.
